================================================================================


FRONTEND DOUBLE-CLICK PREVENTION
=================================

Before:
-------
User clicks Confirm → Form submits immediately
User clicks again   → Form submits again! ❌
Result: Two requests to server, possible race condition


After:
------
User clicks Confirm
    ↓
Check: isSubmitting flag = false?
    ↓ YES
Set isSubmitting = true
Disable button
Show spinner + "Processing..."
    ↓
Form submits
    ↓
User clicks again
    ↓
Check: isSubmitting flag = true?
    ↓ YES
Return early (do nothing) ✅

Result: Only ONE request, no race condition!


================================================================================


EXCEPTION HIERARCHY
===================

                    Throwable ← catch (Throwable $e) catches ALL
                        ↑
                    Exception
                        ↑
                RuntimeException ← catch (RuntimeException $e)
                        ↑
            InvalidArgumentException ← catch (InvalidArgumentException $e)


Catch Order (IMPORTANT):
------------------------
1. catch (RuntimeException $e)         ← Most specific
2. catch (InvalidArgumentException $e) ← More specific  
3. catch (Throwable $e)                ← Most general

PHP matches catches from TOP to BOTTOM, first match wins!

ERROR MESSAGE FLOW
==================

Scenario 1: Document already processed
--------------------------------------
RuntimeException thrown
    ↓
catch (RuntimeException $e)
    ↓
Show: "This assignment has already been processed by another request."
    ↓
User understands: Someone else already processed this document ✅


Scenario 2: Validation error (missing remarks)
----------------------------------------------
InvalidArgumentException thrown
    ↓
catch (InvalidArgumentException $e)
    ↓
Show: "A decline reason is required."
    ↓
User understands: I need to fill in the remarks field ✅


Scenario 3: Database connection error
-------------------------------------
PDOException thrown
    ↓
catch (Throwable $e)
    ↓
Show: "Action failed: SQLSTATE[HY000] [2002] Connection refused"
    ↓
User understands: System error, contact admin ✅


Scenario 4: Genuine lock timeout (rare)
---------------------------------------
PDOException with code 1205
    ↓
catch (Throwable $e)
    ↓
Show: "Action failed: Lock wait timeout exceeded..."
    ↓
User understands: Database was busy, try again ✅
